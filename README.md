# PhotoLab — Веб-редактор растровых изображений

Учебный проект по дисциплине «Технологии компьютерной графики» (ТКГ 09.03.01).  
Приложение представляет собой легковесный графический редактор, реализующий базовые алгоритмы цифровой обработки сигналов и растровых изображений на чистом Canvas API и Web Workers без использования сторонних библиотек машинной графики.

## Реализованная функциональность по лабораторным работам

### Лабораторная работа №1 — Цифровое представление изображения
* Импорт изображений форматов PNG, JPEG/JPG и специализированного бинарного формата GrayBit-7 (GB7).
* Экспорт результатов в форматы PNG, JPEG (с настраиваемым качеством) и GB7.
* Собственный бинарный кодек (энкодер и декодер) для формата GB7, реализованный без сторонних зависимостей на базе `ArrayBuffer`, `Uint8Array` и `DataView`.
* Информационная строка состояния (Status Bar):
  * Имя исходного файла.
  * Формат данных.
  * Геометрические размеры (ширина и высота в пикселях).
  * Глубина цвета с разделением по компонентной структуре (монохромный 8 бит, RGB 24 бит, RGBA 32 бит, GB7 7/8 бит).
  * Разрешение в мегапикселях (Мп).
* Адаптивный пользовательский интерфейс с поддержкой drag-and-drop загрузки.

### Лабораторная работа №2 — Цветовые каналы и инструмент «Пипетка»
* Модуль управления каналами изображения (Channel Panel) с поддержкой 4 структур данных:
  * 1 канал: Grayscale (градации серого);
  * 2 канала: Grayscale + Alpha (градации серого с маской прозрачности);
  * 3 канала: RGB (полноцветное без альфа-канала);
  * 4 канала: RGB + Alpha (полноцветное с прозрачностью).
* Генерация независимых миниатюр предварительного просмотра для каждого канала в градациях серого.
* Селективное включение/выключение каналов с мгновенной перерисовкой на холсте (Canvas):
  * Изоляция компонентов без перезаписи оригинального массива пикселей в памяти.
  * Режим отображения чистой маски прозрачности при активации только альфа-канала.
* Инструмент «Пипетка» (Color Picker):
  * Точное определение координат $(X, Y)$ относительно исходной матрицы пикселей с компенсацией коэффициента масштабирования холста.
  * Считывание значений цветовых каналов $R, G, B \in [0, 255]$ и $A \in [0, 255]$, вывод HEX-кода.
  * Математически точная конвертация цветовых координат в пространство CIE $L^*a^*b^*$ (D65) через промежуточный этап линеаризации sRGB и переход в пространство CIE $XYZ$.

### Лабораторная работа №3 — Градационные преобразования и инструмент «Уровни» (Levels)
* Модальное диалоговое окно коррекции на базе нативного элемента `<dialog>` (`showModal`) с управляемым бекдропом и возможностью свободного перемещения по экрану (Draggable) для исключения перекрытия холста.
* Динамическое построение композитной и поканальной гистограммы распределения яркостей:
  * Композитная яркость вычисляется по формуле: $Y = (76R + 150G + 30B) \gg 8$.
  * Поддержка переключения между линейной и логарифмической шкалой по оси ординат.
* Трехточечный слайдер входных уровней (Input Levels):
  * Точка черного ($[0, 254]$).
  * Точка белого ($[1, 255]$).
  * Нелинейная гамма-коррекция полутонов ($[0.1, 9.9]$, по умолчанию $1.0$).
  * Защита от пересечения маркеров и автоматическое удержание точки гаммы в рабочем диапазоне.
* Архитектура таблиц поиска (Look-Up Table, LUT):
  * Независимое хранение параметров коррекции для композитного канала (Master) и каждого отдельного компонента.
  * Композиция Master LUT и канальных LUT в единую результирующую таблицу для выполнения однопроходной синхронной коррекции.
* Интерактивный предпросмотр в реальном времени с троттлингом через `requestAnimationFrame`.
* Функции сброса текущего канала, полного сброса всех каналов, отмены и окончательного применения.

### Лабораторная работа №4 — Масштабирование изображения
* Собственная реализация алгоритмов двумерной дискретной интерполяции:
  * Метод ближайшего соседа (Nearest Neighbor).
  * Билинейная интерполяция (Bilinear Interpolation) — используется по умолчанию.
* Расширяемый программный реестр алгоритмов интерполяции (`INTERPOLATION_METHODS`).
* Управление отображением на главном экране:
  * Пресеты масштабирования (от 12% до 300%).
  * Плавный ползунок диапазона и кнопки шага.
  * Масштабирование колесом мыши с зажатой клавишей Ctrl.
  * Автоматический расчет оптимального коэффициента вписывания (`fitScale`) при загрузке с сохранением технологического отступа не менее 50 пикселей.
* Модальный инструмент изменения геометрического разрешения (`ResizeDialog`):
  * Пересчет объема данных до и после операции в мегапикселях.
  * Ввод размеров в абсолютных пикселях (px) или относительных процентах (%).
  * Режим пропорционального масштабирования (сохранение Aspect Ratio).
  * Строгая валидация числовых диапазонов.
  * Всплывающие подсказки с теоретическим описанием каждого метода.

### Лабораторная работа №5 — Пространственная фильтрация ядром свёртки
* Модальный инструмент матричной фильтрации на базе ядер свёртки $3 \times 3$.
* Библиотека предустановленных фильтров:
  1. Тождественное отображение (Identity).
  2. Повышение резкости (Sharpening).
  3. Фильтр Гаусса $3 \times 3$ (Gaussian Blur).
  4. Прямоугольное сглаживание (Box Blur).
  5. Горизонтальный оператор Прюитта (Prewitt X).
  6. Вертикальный оператор Прюитта (Prewitt Y).
* Редактируемая матрица коэффициентов $3 \times 3$ с поддержкой дробных (`1/16`, `1/9`) и отрицательных чисел с переходом в пользовательский режим (Custom).
* Выбор целевых каналов обработки (независимое или совместное применение).
* Три стратегии обработки краевых условий без уменьшения размерности матрицы:
  * Заполнение константой (черный цвет, 0).
  * Заполнение константой (белый цвет, 255).
  * Репликация граничных пикселей (Clamp / Replicate Edge).
* Вынос вычислительно емких операций свёртки и масштабирования в фоновый поток Web Worker (`imageProcessor.worker.js`) с передачей прогресса вычислений (0–100%) и защитой от блокировки пользовательского интерфейса.
* Поддержка перетаскивания диалога за заголовок для обеспечения полной видимости интерактивного предпросмотра на основном холсте.

## Спецификация бинарного формата GrayBit-7 (GB7)

Формат GB7 предназначен для компактного хранения монохромных изображений без сжатия с опциональной однобитовой маской прозрачности.

### Структура заголовка (12 байт)

| Смещение (байты) | Размер (байты) | Тип данных | Описание |
|---|---|---|---|
| 0–3 | 4 | `ASCII / Hex` | Сигнатура файла: `0x47 0x42 0x37 0x1D` (`GB7\x1D`) |
| 4 | 1 | `uint8` | Версия формата (текущая версия `0x01`) |
| 5 | 1 | `uint8` | Флаги: бит 0 — наличие маски (0 = нет, 1 = есть); биты 1–7 зарезервированы (0) |
| 6–7 | 2 | `uint16_be` | Ширина изображения в пикселях (Big-Endian) |
| 8–9 | 2 | `uint16_be` | Высота изображения в пикселях (Big-Endian) |
| 10–11 | 2 | `uint16_be` | Зарезервировано: `0x0000` |

### Структура полезной нагрузки (матрица пикселей)

Данные следуют непрерывно построчно от верхнего левого угла к нижнему правому без выравнивания строк. Каждый пиксель кодируется ровно 1 байтом (8 бит):

* **Биты 0–6 (LSB):** Градация серого цвета в диапазоне от 0 до 127 ($[0, 127] \to [0, 255]$ при распаковке).
* **Бит 7 (MSB):** Бит бинарной маски (если в заголовке установлен флаг маски):
  * `0` — пиксель прозрачен (Alpha = 0);
  * `1` — пиксель непрозрачен (Alpha = 255).
  * Если флаг маски в заголовке сброшен (0), бит 7 всегда равен 0.

│   ├── App.jsx                     # Корневой компонент приложения
│   ├── main.jsx                    # Точка входа в React DOM
│   └── index.css                   # Базовые стили и типографика

├── index.html
├── package.json
└── vite.config.js

Стек технологий

  - Фреймворк: React 19
  - Сборщик: Vite 8
  - Стилизация: CSS Modules
  - Работа с графикой: HTML5 Canvas API, TypedArrays (Uint8ClampedArray,
    ArrayBuffer, DataView)
  - Многопоточность: Web Workers API
  - Линтинг: ESLint 10

Инструкция по установке и сборке

Требования

  - Node.js версии 18.0.0 или выше
  - Пакетный менеджер npm

Установка зависимостей

npm install

Запуск локального сервера разработки

npm run dev

После запуска приложение доступно по адресу http://localhost:5173/.

Сборка оптимизированного продакшн-бандла

npm run build

Скомпилированные статические файлы будут сохранены в директорию dist/.

Предпросмотр продакшн-сборки

npm run preview

Проверка исходного кода линтером

npm run lint
